# Contributing

Contributions should be simple, self-contained skills that are safe to share
publicly.

Before opening a pull request:

1. Put the skill in `skills/<skill-name>/` and include a `SKILL.md`.
2. Keep the frontmatter name aligned with its directory name.
3. Add a small test or other reproducible verification when the skill has code.
4. State third-party dependencies and licenses; do not copy code without its
   license and attribution requirements.
5. Run a public-safety review: no secrets, private paths, internal systems,
   personal data, or non-public workflow details.
